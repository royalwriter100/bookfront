# Bookfront UI mockups

Approved UI mockups for Bookfront, in three folders:
- `landing/` is the marketing landing page
- `sales-page/` is the sample book sales page (He Was My First Love)
- `dashboard/` is the author dashboard prototype (hash routes: dashboard, books, 7-step add-book wizard with 6 templates, orders, readers, emails, campaigns, referrals, marketing hub, launch kit, payouts, settings)

Open any `index.html` in a browser to view it. These are static mockups with sample data and no backend.
